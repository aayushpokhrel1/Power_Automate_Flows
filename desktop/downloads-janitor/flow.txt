# Downloads Janitor  -  Power Automate Desktop paste-in
# =============================================================================
# HOW TO USE: open a new PAD flow, click the empty workspace, and paste the
# block BELOW the line marker (everything from "System.GetEnvironmentVariable"
# down). PAD reconstructs the actions.
#
# This paste text is a CONVENIENCE and is best-effort across PAD versions.
# If the paste fails or an action looks off, recipe.md is the source of truth,
# build it there in ~10 minutes. Lines starting with # are comments; PAD
# ignores them, but if a paste ever chokes, delete the comment lines first.

# ---- 8< ---- paste from here ---- 8< ----

System.GetEnvironmentVariable EnvironmentVariableName: $'''USERPROFILE''' EnvironmentVariableValue=> UserProfile
SET DownloadsFolder TO $'''%UserProfile%\\Downloads'''
SET DryRun TO True
SET Report TO $''''''

# --- Images ---
Folder.GetFiles Folder: $'''%DownloadsFolder%''' FileFilter: $'''*.jpg;*.jpeg;*.png;*.gif;*.webp;*.svg;*.bmp;*.heic;*.tiff;*.ico''' IncludeSubfolders: False FailOnAccessDenied: True Files=> MatchedFiles
IF MatchedFiles.Count > 0 THEN
    Folder.IfFolderExists.DoesNotExist Path: $'''%DownloadsFolder%\\Images'''
        Folder.Create FolderPath: $'''%DownloadsFolder%''' FolderName: $'''Images''' Folder=> NewFolder
    END
    SET Report TO $'''%Report%Images: %MatchedFiles.Count%;  '''
    IF DryRun = False THEN
        File.Move Files: MatchedFiles Destination: $'''%DownloadsFolder%\\Images''' IfFileExists: File.IfExists.DoNothing MovedFiles=> MovedFiles
    END
END
